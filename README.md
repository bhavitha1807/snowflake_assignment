# Snowflake Tutorial Assignment

## Overview

This repository contains the complete Snowflake Tutorial Assignment covering SnowSQL connection, Snowflake object creation, data loading, Time Travel, and data recovery.

## Tasks Covered

### 1. SnowSQL Login and Connection
- SnowSQL connection verification
- Current user
- Current role
- Current warehouse
- Current database
- Current schema

### 2. Creation of Snowflake Objects
- Database
- Schema
- Warehouse
- Table
- Stage
- INSERT, SELECT, UPDATE, and DELETE operations

### 3. Data Loading Using SnowSQL
- Sample dataset creation
- Stage creation
- Data loading using `COPY INTO`
- Data verification

### 4. Snowflake Time Travel
- UPDATE and DELETE operations
- Viewing previous table versions using Time Travel
- Querying data from an earlier point in time

### 5. Data Recovery Using Time Travel
- Identifying accidentally deleted records
- Recovering deleted records using Time Travel
- Verifying the recovered data
